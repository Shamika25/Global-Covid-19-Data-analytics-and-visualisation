**GLOBAL COVID 19 ANALYSIS AND VISUALISATION**

This Power BI dashboard provides a comprehensive and interactive view of the global impact of COVID-19. It includes key metrics like total cases, deaths, recoveries, active cases, and fatality rates across various countries and continents over time. Users can explore data by country, continent, and custom date ranges to gain insights into the evolution of the pandemic.

**Objective** -
The main goal of this project is to:Analyze and visualize global COVID-19 data to uncover trends, identify high-risk regions, and support data-driven public health decisions.

**Specific objectives**:

Track daily and cumulative COVID-19 statistics globally

Identify top-impacted countries and continents

Understand case fatality and recovery rates

Provide policymakers and citizens with intuitive insights

**Business Problem-**
During the pandemic, decision-makers around the world faced a critical lack of real-time, visual insights into how the virus was spreading and affecting various regions.

**Challenges:**
Inconsistent data reporting across countries

Difficulty in tracking dynamic changes in cases/deaths

Lack of centralized visualization for global comparison

Need for fast and clear communication of risk areas

💡**Solution Provided**
This project addresses the above business problem by:

✅ Creating a centralized dashboard to consolidate global COVID-19 data
✅ Using visual storytelling (maps, charts, KPIs) for better understanding
✅ Enabling users to filter by country/continent/date for flexible exploration
✅ Tracking trendlines and rates for deeper health insights
✅ Supporting real-time, informed decision-making at individual and government levels
